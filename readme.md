# Calculator

A multi-purpose **Calculator website** built using **HTML, CSS, and JavaScript**.

The website provides three different calculators in a single application:

* **Standard Calculator**
* **Programmer Calculator**
* **Unit Calculator**

## Live Demo

Try the calculator website here:

[Calculator Website](https://jimmyjayant.github.io/Calculator/?utm_source=chatgpt.com)

## Features

### 1. Standard Calculator

The Standard Calculator is designed for everyday mathematical calculations.

It supports common arithmetic operations such as:

* Addition
* Subtraction
* Multiplication
* Division
* Basic mathematical calculations
* Clear and reset functionality

### 2. Programmer Calculator

The Programmer Calculator is designed for calculations involving different number systems and programming-related operations.

It can be used for working with:

* Binary numbers
* Decimal numbers
* Hexadecimal numbers
* Other programmer-oriented calculations

### 3. Unit Calculator

The Unit Calculator allows users to perform conversions between different units.

It can be used for converting values between supported measurement units, making it useful for everyday calculations and measurements.

## Technologies Used

* **HTML5** – Used to create the structure and layout of the calculators.
* **CSS3** – Used for styling and designing the user interface.
* **JavaScript** – Used to implement calculator operations, conversions, and user interactions.

## How to Use

1. Open the [Calculator Website](https://jimmyjayant.github.io/Calculator/).
2. Select the calculator you want to use:

   * Standard
   * Programmer
   * Unit
3. Enter the required values using the calculator interface.
4. Select the desired operation or conversion.
5. View the calculated result.

## Running Locally

To run the project locally:

```bash
git clone https://github.com/jimmyjayant/Calculator.git
```

Navigate to the project directory:

```bash
cd Calculator
```

Then open `index.html` in a web browser.

No additional dependencies or installation are required.
